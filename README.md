## راه‌اندازی روی GitHub Pages

### مرحله ۱ — آپلود فایل‌ها
1. وارد GitHub بشید: https://github.com/iEhsanbh
2. روی **New repository** کلیک کنید
3. نام: `music-app` (یا هر نام دلخواه)
4. گزینه **Public** رو انتخاب کنید
5. روی **Create repository** کلیک کنید
6. فایل‌ها رو آپلود کنید:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`

### مرحله ۲ — فعال کردن GitHub Pages
1. وارد Settings ریپازیتوری بشید
2. از منوی چپ روی **Pages** کلیک کنید
3. زیر Source، گزینه **Deploy from a branch** رو انتخاب کنید
4. Branch: **main** و folder: **/ (root)** رو انتخاب کنید
5. **Save** کنید

### مرحله ۳ — دسترسی به اپ
چند دقیقه صبر کنید، بعد اپ روی این آدرس در دسترسه:
```
https://iEhsanbh.github.io/music-app/
```

### نصب روی گوشی اندروید
1. لینک بالا رو در Chrome باز کنید
2. منوی سه‌نقطه بالا رو بزنید
3. **Add to Home screen** رو انتخاب کنید
4. اپ مثل یه برنامه واقعی نصب می‌شه!

## اضافه کردن اطلاعات جدید

تمام داده‌ها در فایل `index.html` در بخش `const DATA = {...}` هستند.

### اضافه کردن متن ترانه
پیدا کنید:
```javascript
title:"دست‌های تو", lyrics:""
```
و متن رو بین گیومه‌ها بنویسید:
```javascript
title:"دست‌های تو", lyrics:"دست‌هایت را بده..."
```

### اضافه کردن خواننده جدید
در بخش `const DATA` یه آبجکت جدید مثل `dariush` یا `hayedeh` اضافه کنید.
